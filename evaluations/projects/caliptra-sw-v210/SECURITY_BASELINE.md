## Inclusion & Stratification Methodology

Every commit merged to `chipsalliance/caliptra-sw` `main` after `fw-2.1.0` (`7da3b01b8b1806af0ec491c5e3e3e7cac91a3561`) was audited against four objective criteria:

1. **Post-Snapshot Fix**: Merged strictly after `fw-2.1.0` (`2026-03-10T17:33:47Z`).
2. **Verified Unpatched Presence at `fw-2.1.0`**: Hunk-level inspection against the `fw-2.1.0` source tree confirms the vulnerable function and defective code path already existed at `7da3b01b8b18` (excluding regressions introduced by post-`fw-2.1.0` feature PRs; see [Excluded Post-`fw-2.1.0` Regressions & Out-of-Scope Fixes](#excluded-post-fw-210-regressions--out-of-scope-fixes)).
3. **On-Target Firmware Scope**: Resides in the 10 on-target Caliptra Core RISC-V firmware crates (excluding host-side `libcaliptra`, FPGA scripts, software emulator models, and CI infrastructure).
4. **CWE-Classified Security Defect**: Addresses a concrete vulnerability or hardware/cryptographic security invariant (excluding pure FIPS Known-Answer / Pairwise-Consistency self-test additions that do not fix defective logic).

To support both strict CVE recall and broader security-bug recall without conflating severity classes, the `36` verified upstream items are stratified into three tiers:

| Baseline Tier                                         |  Count   | Description                                                                                                                                                                     |
| :---------------------------------------------------- | :------: | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Tier A — Published CVEs / GHSAs**                   | **`5`**  | Official GitHub Security Advisories & NVD CVEs disclosed between June and August 2026                                                                                           |
| **Tier B — Maintainer-Patched Security Bugs**         | **`22`** | Exploitable access-control (PAUSER PL0), auth/manifest verification, memory/address bounds, TOCTOU, and cryptographic validation bugs patched upstream without separate CVE IDs |
| **Tier C — Zeroization, Attestation & SCA Hardening** | **`9`**  | Secret zeroization leaks (`CWE-226`), missing DICE attestation state, fault/fatal-handler bypass, and side-channel masking seed fixes                                           |
| **Combined Core Security Bugs (`Tier A + Tier B`)**   | **`27`** | All exploitable/functional security vulnerabilities present at `fw-2.1.0`                                                                                                       |
| **Complete Security Baseline (`Tier A + B + C`)**     | **`36`** | Full post-`fw-2.1.0` upstream security & cryptographic hardening baseline                                                                                                       |
