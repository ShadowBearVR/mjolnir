What is a Security-relevant Bug?

We use the term security-relevant bug for any bug that violates a security property in the project’s threat model, whether or not it is exploitable in a deployed system.

This includes exploitable vulnerabilities, but also weaknesses such as a missing countermeasure that maintainers would fix for security reasons.

Whether a candidate finding is a security-relevant bug can depend heavily on the project’s threat model and trust boundaries, such as which boot stage trusts which input.
